# Só DMs

App para iPhone que abre o Instagram direto nas mensagens e bloqueia todo o resto:
feed, Explorar, aba Reels, busca, notas e a rolagem de reels/stories.

- Liberado: inbox, conversas, grupos, solicitações, respostas de stories, o reel/post/story que te mandaram (só ele) e o perfil de quem está na conversa (sem a grade de posts).
- As regras ficam em `SoDMs/so-dms.user.js` (ajustes no topo do arquivo).

## Baixar

Última versão: https://github.com/figuered0o0808-glitch/so-dms/releases/latest/download/SoDMs.ipa

Instale pelo SideStore (Meus Apps > +, escolha o arquivo SoDMs.ipa).

A cada alteração enviada para o GitHub, uma nova versão é gerada automaticamente (aba Actions).

## Trocar o ícone

Envie uma imagem (png ou jpg) para a pasta `icone/`:
https://github.com/figuered0o0808-glitch/so-dms/upload/main/icone

O GitHub gera uma versão nova com o ícone em uns 3 minutos. Depois é só reinstalar pelo SideStore.
